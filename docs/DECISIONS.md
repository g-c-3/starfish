

**494. ods formulas (Phase 120 step 5b1).** A formula of an ods (`of:=SUM([.A1:.A3])+[$Sheet2.B1]`) is turned into the A1 text that `xlsxcalc.js` reads (`SUM(A1:A3)+Sheet2!B1`) and back; a sheet name with a space or a symbol is quoted. Strings are copied as they are, `;` between arguments and `,` swap. A reference form that is not understood (a range over two sheets, an error reference, a quoted name outside a reference) makes the formula not covered: its stored result stays (Decision 453, rule 3) and the cell is shown as holding a formula that a typed one replaces. Typed `=…` is read as in the xlsx editor (Decision 491: the same functions, the same refusals for an unknown function, name or sheet and for a cell that refers to itself, directly or through others, with the cell left as it was); a whole column or row is refused, because the written ods text has no form for it. After every change all formulas of the workbook, hidden sheets too, are calculated again in dependency order and a result is stored only when it differs; date and time cells are read as spreadsheet numbers; a formula in a cell that stands for several repeats, and a formula whose cell holds a date or time, keep their stored results. A result is written as a number (a percent or currency cell keeps its kind and currency), text, TRUE or FALSE, or an error as text with the error kind where the file declares it. A formula cell can be overwritten or cleared by a value; an array formula start and the cells it covers are refused. This replaces the Decision 493 refusal of workbooks that hold formulas. `xlsxcalc.js` gains TRUE() and FALSE(). Not done: ods formats, rows, columns and sheets (steps 5b2, 5b3), formulas that read a range over several sheets. About 10 KB of source added (Decision 453).
