

**496. ods rows, columns and sheets (Phase 120 step 5b3).** `odsedit.js` gains `insertRows`, `deleteRows`, `insertCols`, `deleteCols`, `renameSheet`, `addSheet` and `deleteSheet`, with the signatures of the xlsx engine, so the view shows the Rows and columns and Sheets groups for an ods without a change. A row or cell stands for its repeats: an insert splits the element that holds the place and puts a new row (or cell, in every row) before it, a delete lowers or removes the repeat counts it covers; the declared columns follow. Every formula of every sheet is read as A1 text (Decision 494), rewritten by `xlsxrefs.js` (a reference that is cut becomes `#REF!`, written `[.#REF!]`) and written back only where the text changed; all formulas are then calculated again. A sheet rename rewrites the sheet prefix of formulas; a delete turns references to the sheet into `#REF!` and keeps at least one sheet; a new sheet is empty and follows the last one; a sheet name follows the xlsx rules (1 to 31 characters, not `: \\ / ? * [ ]`, no apostrophe at the ends, not the name of another sheet). Refused with a message, leaving the file as it was: a workbook that holds named ranges, database ranges, pivot tables, validation, filters, conditional formats, drawings, pictures, charts or print ranges, array formulas, or a formula that cannot be read as A1 text (a range over two sheets, an unknown syntax) — each holds cell addresses this editor does not move — for rows, columns, rename and delete (adding a sheet is allowed); and a row or column change that would cut a merged cell (an insert inside it, a delete that covers it in part); a delete that covers a merged cell whole removes it. Not done: moving merged cells' spans, row and column heights and hidden state on insert, named ranges, validation, conditional formats, pictures and charts. About 8 KB of source added (Decision 453). Phase 120 is complete for xlsx and ods; xls follows Phase 122.
