

**495. ods number formats (Phase 120 step 5b2).** A format is an ods number style in the automatic styles of `content.xml`, referenced by an automatic cell style. `src/js/odsfmt.js` turns one section of a format code into number-style, percentage-style, date-style, time-style or text-style parts and back: digits with a grouping and decimals (`0`, `0.00`, `#,##0.00`), a `%`, quoted or escaped text before and after, years, months (numbers or names), days (numbers or names), hours, minutes (an `m` beside hours or seconds), seconds, AM/PM, and `@`. Refused with a message: several sections, colors, conditions, fractions, scientific form, other digit patterns, letters that are not a part. `odsedit.js` `format` gives the code of a cell's style (the cell's, else its column's default; styles from `styles.xml` are read), General, or empty when the style holds parts this editor does not read. `setFormat` writes one data style per code and one cell style per base style and data style in a session; an automatic base style is cloned so its other properties stay, a named base style becomes the parent; General removes the data style, and is refused where the format comes from a named style. The shown text follows: a number is written formatted, a float under a percent format becomes a percentage and back, a date or time cell under a format that is not a date or time becomes a float with the date's serial; typed numbers and calculated results are written formatted too (a formatted percent or currency cell keeps its kind). Nothing is written for the code a cell already has. The Format group of the view shows for an ods. Not done: formats of a whole row or column, several cells at once, a named style as the format, the dates of a date cell as other than a serial under a non-date format.
